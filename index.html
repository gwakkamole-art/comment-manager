API 키 무료 발급 가이드

구글 제미나이(Gemini) AI를 사용하기 위한 열쇠를 무료로 발급받는 방법입니다. 딱 1분이면 됩니다!

1️⃣ 구글 계정으로 로그인한 상태에서 아래 발급 센터 이동 버튼을 클릭합니다.
2️⃣ 사이트 왼쪽 상단 메뉴에 있는 파란색 [Get API key] 버튼을 누릅니다.
3️⃣ 화면 중앙의 [Create API key] 버튼을 누르고, 뜨는 팝업에서 초록색 버튼(Create API key in new project)을 한 번 더 클릭합니다.
4️⃣ AIzaSy... 로 시작하는 긴 텍스트가 나타나면 옆에 있는 [Copy] 버튼을 눌러 복사합니다.
5️⃣ 복사한 키를 이곳 댓글 비서 화면의 API Key 설정 칸에 붙여넣기 하시면 완료됩니다! (자동 저장됨)
