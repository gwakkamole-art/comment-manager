매일 쏟아지는 유튜브 댓글 관리, 이제 AI 비서에게 맡기세요! 처음 오신 분들은 아래 순서대로 따라 해보시면 됩니다.

🔑 0단계: 준비하기 (최초 1회)

상단의 'Google API Key 설정' 칸에 발급받은 키를 입력하세요. (발급 방법을 모른다면 바로 밑의 '❓ 무료 발급 가이드' 버튼을 눌러보세요!) 한 번 입력하면 내 PC에 자동 저장됩니다.

📌 1단계: 담당 채널 선택 & 설정

왼쪽 목록에서 관리하는 채널을 클릭하세요. (초성 검색 가능) 채널명 옆의 톱니바퀴(⚙️) 아이콘을 누르면 해당 채널의 성격과 답변 말투(페르소나)를 내 맘대로 바꿀 수 있습니다.

💬 2단계: 시청자 댓글 입력하기

시청자가 남긴 댓글을 우측 텍스트 칸에 복사해서 붙여넣습니다.
💡 [초강력 꿀팁] 유튜브 화면을 캡처(Win+Shift+S)한 뒤 화면 아무 곳이나 클릭하고 Ctrl+V 해보세요! AI가 캡처 이미지 속 글자를 알아서 읽습니다.

✨ 3단계: 찰떡 답변 생성 및 악플 판독

파란색 [답변 및 판단 생성하기] 버튼을 누르세요. AI가 채널 성격에 맞는 답변을 대신 써줍니다. 만약 욕설이나 비방이라면 AI가 알아채고 ⚠️ [삭제 권장] 경고를 붉은 글씨로 띄워줍니다.

🧹 4단계: 다음 댓글로 넘어가기

작업이 끝났다면, 입력창 위의 [내용 비우기] 버튼을 눌러 화면을 깨끗하게 정리하고 다음 댓글 작업을 시작하세요!

API 키 무료 발급 가이드

구글 제미나이(Gemini) AI를 사용하기 위한 열쇠를 무료로 발급받는 방법입니다. 딱 1분이면 됩니다!

1️⃣ 구글 계정으로 로그인한 상태에서 아래 발급 센터 이동 버튼을 클릭합니다.
2️⃣ 사이트 왼쪽 상단 메뉴에 있는 파란색 [Get API key] 버튼을 누릅니다.
3️⃣ 화면 중앙의 [Create API key] 버튼을 누르고, 뜨는 팝업에서 초록색 버튼(Create API key in new project)을 한 번 더 클릭합니다.
4️⃣ AIzaSy... 로 시작하는 긴 텍스트가 나타나면 옆에 있는 [Copy] 버튼을 눌러 복사합니다.
5️⃣ 복사한 키를 이곳 댓글 비서 화면의 API Key 설정 칸에 붙여넣기 하시면 완료됩니다! (자동 저장됨)
